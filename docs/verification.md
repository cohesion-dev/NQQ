## 灵矽真实语音播放

已移除角色回复的浏览器文字朗读。网关转发服务端下行音频参数、语音状态和原始二进制帧，页面使用实际 Opus 解码器和浏览器音频上下文播放；字幕只显示文字。正常结束等待解码和音源排空，打断或断线立即清空，旧连接与旧异步任务不能恢复旧语音。嘴型读取输出采样振幅，播放期间暂停麦克风，结束后恢复；自然结算保留监听，本地结算提示仅显示字幕。

本次 `npm test` 与 `npm run build` 通过。新增[音频测试](../tests/linx-audio.test.ts)使用有效的二十毫秒 Opus 包，经过真实 WebAssembly（浏览器可运行的二进制模块）解码，核对 16/24/48kHz 采样率、帧长度、连续调度及十六位小端 PCM（脉冲编码调制）采样值；同时验证正常结束排空、空回复、取消与解码竞争、迟到结束事件、格式错误恢复、自动播放限制提示和恢复。网关转发与浏览器收包测试验证二进制不进入文字解析、打断后过滤残留帧和重连隔离。

测试中的扬声器可控，不代表实际听感。本次浏览器自动检查因 Chromium 启动时系统权限拒绝而未执行；尚未进行控制台两种音色切换试听、真实麦克风对话和 iPhone 真机录放音验收。联调时重启网关并刷新页面，保存音色配置后建立新连接；播放受限时轻触页面解锁。协议依据见[官方音频协议](https://linx.qiniu.com/docs/xrobot/platform/websocket)和[音色配置指引](https://linx.qiniu.com/docs/xrobot/guide/agent-config)。
