# 当前开发验证记录

本记录针对模型和声音占位的移动网页版本。功能测试通过的范围仅限下表；模块计划中的完整验收仍未完成，不能由此宣称全部计划通过。

| 检查 | 结果 | 已验证范围 |
| --- | --- | --- |
| `npm test` | 通过 | 可控时间的游戏规则、真实接触时刻、补位、停止、疲惫、截止；聊天/游戏工具参数拒绝；页面电话入口契约；VAD 音量帧和 44.1kHz/48kHz 到 16kHz 音频分帧 |
| `npm run typecheck` | 通过 | 网页、网关、共享工具和测试代码的类型检查 |
| `npm run build` | 通过 | 生产页面和音频工作线程可构建 |
| `git diff --check` | 通过 | 已跟踪修改的空白格式 |
| 开发服务 HTTP 请求 | 通过 | 页面可访问，`/api/config` 返回未配置，`/api/session` 可建立本地会话 |
| 无配置的设备连接 | 通过 | WebSocket（双向长连接协议）握手后返回 `LINX_NOT_CONFIGURED`，不伪造接入成功；探测工具读取错误帧后超时结束 |
| 浏览器自动化 | 阻塞 | 本环境禁止启动浏览器进程，未取得截图或真实页面操作结果；已提供 `npm run test:browser` 供可启动浏览器的环境运行 |
| 真实灵矽握手 | 通过 | 使用本地密钥只读查询到唯一的牛七七智能体，补齐本地编号；真实设备连接完成握手与工具发现，网关返回就绪 |
| 聊天/游戏模式联调 | 未执行 | 尚未验证真实麦克风聊天、`start_apple_game` 工具触发、游戏结束后回到聊天和普通问答 |
| iPhone 与原生外壳 | 未执行 | 尚无真机记录，原生外壳未制作 |

当前可以用 `npm run dev` 启动网页及同源开发网关。页面默认聊天，真实工具触发开始游戏；连接配置与验收步骤见[灵矽联调指南](linx-integration.md)。

本次模型和声音替代方式由用户授权：程序化三维牛和动作代替正式素材；浏览器朗读代替灵矽下行音色。它们不计为正式 GLB（三维模型二进制传输格式）、完整动作资源或真实语音解码交付。
