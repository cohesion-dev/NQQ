# M5 执行计划：灵矽接入与会话

本计划面向接入负责人，目标是让真实灵矽对话调用游戏工具并收到实际结果。状态为待评审、未实施；外部接口依据[实现方案第 5 节](../implementation-plan.md)，验收记录见[统一要求](README.md)。

## 1. 范围、依赖与交付

- 负责 `server/`、`web/src/linx/` 及接入、配置和排障说明。
- 输入：服务端灵矽配置、浏览器会话、玩家文字与音频、M1 实际工具结果。
- 输出：已校时的本局信息、工具请求、识别文字、回复文字、规范化音频和连接状态。
- 负责协议适配与路由，不在网关里实现牛移动、苹果坐标或计分。

真实验证需要可用账号、支持工具调用的智能体、服务端访问密钥、音色与额度。凭证通过服务端配置提供，不要求发送到对话或写进前端资源。

## 2. 执行步骤与阶段产物

| 阶段 | 工作 | 交付物 | 验证项 |
| --- | --- | --- | --- |
| M5-1：可行性验证 | 验证虚拟身份、激活绑定、密钥权限、文字入口与实际音频 | 脱敏请求响应、可用参数和未确认项清单 | 将文档假设变为真实账号证据，尽早反馈 M0/M4 |
| M5-2：设备连接 | 建立会话隔离、鉴权、初始化与清理 | 可连接的设备适配和页面状态事件 | 未绑定不冒充就绪，断开可清理 |
| M5-3：工具协议 | 实现初始化、工具发现、调用、结果、去重与取消 | 最小执行器与真实调用演示 | 一次请求对应一次实际执行和一个最终结果 |
| M5-4：文字与音频 | 接普通文字、监听控制、音频传输、解码和打断 | 与 M4 共用的实际格式与聊天链路 | 动作和普通问答都可完成 |
| M5-5：本局与整合 | 签发固定截止时间，路由 M1，处理多会话和异常 | 网页适配、真实游戏记录与运行说明 | 截止、旧请求、断线和跨用户行为准确 |

首轮可人工绑定一个设备验证链路，但最终多用户验收还要通过自动绑定及会话隔离。遇到平台能力与文档不一致时保留响应证据，先与用户确定调整再依赖该能力开发。

## 3. 必验标准

| 编号 | 给定条件与操作 | 预期结果 | 验证方式 |
| --- | --- | --- | --- |
| M5-A01 | 使用未绑定虚拟设备请求网关，再实际绑定并重新请求 | 未绑定取得激活信息；绑定后取得可用设备连接凭证；虚拟身份获服务接受 | 脱敏真实响应 |
| M5-A02 | 无效密钥、绑定失败或额度不可用时请求连接 | 不报告就绪、不启动运行中的局；输出英文协议错误和可映射状态 | 失败响应和页面状态 |
| M5-A03 | 建立设备连接并完成 `hello`、工具初始化和列表交换 | 保存实际会话与音频参数，完成后才报告就绪；无编号通知不产生错误响应 | 协议时间线 |
| M5-A04 | 发现工具并请求动作和状态查询 | 名称及参数符合唯一契约；状态查询不暴露苹果坐标，非法参数不执行 | 工具列表和输入验证 |
| M5-A05 | 最小执行器接到请求，先延迟完成，再返回实际结果 | 网关等待真实结果；返回相同请求编号，不把入队当完成 | 请求与响应匹配记录 |
| M5-A06 | 重复请求、未知工具、无效参数、执行取消或结果超时 | 已有请求不重复执行；失败或取消只结束一次，不自动重放不确定动作 | 协议模拟与结果计数 |
| M5-A07 | 真实提交“向左走一步”和一个普通问题作为文字输入 | 前者触发真实工具，后者产生实际回答及音频；非仅显示本地文字 | 真实文字链路记录 |
| M5-A08 | 按手动监听协议上传真实语音并停止监听 | 识别文字正确到达，普通问答和动作请求均走实际服务 | 监听、识别、调用和回复记录 |
| M5-A09 | 检查实际上传与下行编码，并与 M4 播放 | 参数与实际字节一致；需要解码时对原始帧正确解码，输出符合共享格式 | 编码记录、样本和实际听感 |
| M5-A10 | 旧音频正在传输时发送打断并开始新一轮 | 上游打断与页面代次同步，旧音频不错误地标记为新音频 | 与 M4 的真实打断时间线 |
| M5-A11 | 两个独立浏览器会话同时绑定、对话并调用工具 | 设备、请求、音频和页面路由隔离；不能用另一会话的编号调用其设备 | 双会话演练 |
| M5-A12 | 开局、等待、断线重连，并跨过原截止时间 | 同一局仍使用原截止时间；到点拒绝旧动作、取消等待并关闭上游连接 | 服务端时间与事件记录 |
| M5-A13 | 旧连接的工具或音频迟到，新局已经启动 | 不路由到新局、不重复执行，未匹配编号的结果不被接收 | 连接代次与跨局模拟 |
| M5-A14 | 浏览器关闭、用户结束或本局到期后检查服务 | 连接、工具等待、解码器和定时任务释放；后续可创建新局 | 生命周期与资源记录 |
| M5-A15 | 审查网页构建、错误、请求日志与验证资料 | 不含管理密钥或设备连接凭证；错误和日志为英文，状态可映射中文 | 资源和脱敏检查 |

M5-A10 不能只在自有消息上添加播放编号就宣称通过。若上游原始音频帧没有轮次标识，需要依据实测的控制消息边界区分旧流和新流，并与 M4 一起验证延迟帧场景。

## 4. 延迟与默认规则验证

在实际目标环境记录至少 10 次语音动作请求，保存说话停止、识别到达、工具到达、动作开始、动作完成和回复开始时间。分别统计样本中位数与第 95 百分位，不填写猜测值；说明设备、网络、模型和音色。

这份延迟记录用于 M0 的默认 3 秒苹果寿命验收，不等同于游戏可玩性已经通过。若多数指令到达时苹果已过期，反馈实际证据；不得静默延长寿命、忽略苹果到期或绕过灵矽假装语音已生效。

## 5. 联调、交付与阻塞

交付设备与会话代码、网页连接适配、配置说明、实际命令、工具与音频样本、失败恢复说明及验收证据。与 M1 联验实际动作结果，与 M4 联验音频，与 M0 联验本局截止及多用户，与 M6 联验真实网页容器。

缺少账号、绑定权限、额度或可用文字入口时，标记具体必验项阻塞。允许其他模块基于固定样例推进，但本模块不能提前交付为“已接通灵矽”。
