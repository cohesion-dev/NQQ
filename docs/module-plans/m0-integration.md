# M0 执行计划：共享契约与应用集成

本计划面向集成负责人，负责让各模块按同一契约并行开发并最终运行。当前状态为待评审、未实施；验收记录遵循[统一要求](README.md)。

## 1. 范围与依赖

负责 `shared/`、根依赖与锁文件、构建配置、`web/src/main.ts`、共享样例和整体联调记录。模块内部业务实现由对应负责人维护；集成入口只装配和路由。

开始前复核[产品选择](../implementation-plan.md)、[目录归属](../parallel-development.md)，登记每个模块负责人。产品待定项包括角色、方向、自动抓取、疲惫和语音交互方式，确认后记录依据，不能替用户补作决定。

## 2. 执行步骤与阶段产物

| 阶段 | 工作 | 交付物 | 验证项 |
| --- | --- | --- | --- |
| M0-1：契约准备 | 会同使用方定义游戏快照、事件、动作请求/结果、会话与音频契约 | 一份共享定义及有效、失败、取消样例 | 字段单位、必填条件、时间、坐标和所有权完整 |
| M0-2：项目基础 | 建立网页、网关和共享代码的最小构建；登记实际命令与依赖负责人 | 可重复安装、类型检查和构建的工程基础 | 空模块可以引用同一契约，无复制类型 |
| M0-3：本地装配 | 连接游戏逻辑、三维场景、页面和本地音效；用固定时间和随机数据演练 | 本地完整游戏入口与调试方式 | 一个苹果事件只改变一次分数，界面与快照一致 |
| M0-4：真实接入 | 连接 M4/M5，贯通工具输入、实际执行结果、字幕和音频 | 真实文字、语音驱动的游戏 | 一条请求沿全链路可追踪，取消和结束正确传播 |
| M0-5：跨端验收 | 与 M6 完成目标设备、后台和两个玩家测试 | 完整验收记录与问题清单 | 必验项全部通过，未验证能力单列 |

共享时间入口接收 M5 的服务端时间依据，M1 负责截止规则，M2/M3 消费结果；前后台校时不能生成新的游戏截止时间。根目录构建配置与依赖锁由 M0 统一修改。

## 3. 共享契约应落实的内容

- 游戏状态、苹果槽、事件和请求的唯一编号；同一事件可被多个模块消费但不重复产生业务结果。
- 动作参数、一步的距离与方向、请求去重、等待与停止的语义，以及执行完成/取消/拒绝的结果。
- 本局编号、连接代次、开始与截止时间，断开和恢复时哪些数据作废。
- 音频采样参数、帧顺序、播放代次、结束和打断；M4 与 M5 共同确认格式。
- 准备、进行和结算的页面快照；本地演示与真实连接的状态必须可区分。
- 三维资源清单、骨骼节点命名、动作片段名称、动作优先级和打断规则；运行时只依赖导出的 GLB，源文件和导出文件的版本可追溯。

## 4. 必验标准

| 编号 | 给定条件与操作 | 预期结果 | 验证方式 |
| --- | --- | --- | --- |
| M0-A01 | 各模块引用共享契约并执行实际类型检查与构建 | 字段来源唯一，网页和网关检查通过，无各自维护的副本 | 检查输出与引用审查 |
| M0-A02 | 用同一快照输入场景和页面，推进一次游戏更新 | 位置、苹果数、分数和时间一致；仅 M1 更改游戏事实 | 固定样例及调用记录 |
| M0-A03 | 开始一次本局，记录页面与网关的截止时间 | 两端使用同一本局编号和截止时间，等待和重连不重置 | 脱敏时间记录 |
| M0-A04 | 分别用按钮、文字和真实语音请求同一方向动作 | 均进入同一个动作执行入口，返回实际结果 | 三条端到端记录 |
| M0-A05 | 同一苹果抓取事件重复传给表现模块 | 分数只加一次，入袋和提示不无限重复 | 固定事件回放 |
| M0-A06 | 当前有动作和播报时开始录音，再触发停止动作 | 录音取消旧播报；停止动作另行取消位移与等待队列 | 时间线和录屏 |
| M0-A07 | 在截止前请求移动，执行跨过第 60 秒 | 到截止时刻取消剩余动作，不再抓取、补位或加分；网关结束本局连接 | 可控时间与真实一分钟试玩 |
| M0-A08 | 两个浏览器上下文同时开局并发指令 | 请求、分数、字幕和音频不串台 | 两局编号及独立结果 |
| M0-A09 | 旧局延迟返回工具结果或音频，再开新局 | 旧结果不改新局、不播放、不移动角色 | 延迟注入记录 |
| M0-A10 | 按 M6 的步骤进入后台并在截止后恢复 | 直接结算，游戏不获得额外时间，不重放旧请求 | iPhone 真机录屏和截止记录 |
| M0-A11 | 默认 3 秒寿命下，通过真实语音指挥抓到苹果，并完成一分钟 | 至少验证一次真实语音抓取；结算与实际事件数一致，保留全链路延迟 | 固定随机样例、语音与抓取时间记录 |
| M0-A12 | 检查最终构建和启动说明，按说明从新工作目录运行 | 网页与网关可启动，密钥仅从服务端配置读取 | 安装、构建、启动输出及资源检查 |
| M0-A13 | 从新工作目录加载最终网页并播放完整动作演示 | 三维 GLB、贴图和动作可由相对路径加载；不依赖素材负责人的本机路径，模型和动作版本与清单一致 | 构建产物、资源清单和动作播放记录 |

M0-A11 不通过时，记录可玩性未通过并与用户讨论；不能通过临时延长苹果寿命来宣称默认规则已通过。

## 5. 交付与阻塞处理

交付共享契约、项目基础、装配代码、实际开发与构建说明、完整验收证据和未完成项。缺账号、目标设备、产品选择或契约争议时，记录影响范围，允许不依赖该项的模块继续，不虚报完整链路通过。

M0 复核其他模块独立验收后再组织联调；整体完成还需用户评审角色、音效和交互体验。
