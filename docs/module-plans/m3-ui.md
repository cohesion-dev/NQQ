# M3 执行计划：页面与交互

本计划面向页面负责人，目标是让玩家清楚完成准备、指挥、聊天和结算。状态为待评审、未实施；页面业务依据[实现方案](../implementation-plan.md)，验收记录见[统一要求](README.md)。

## 1. 范围、依赖与交付

- 负责 `web/src/ui/`、页面样式与界面资源；根应用入口由 M0 负责。
- 输入：游戏与连接快照、识别文字、回复文字、权限状态和操作结果。
- 输出：开始、方向、停止、文字提交、录音手势等玩家意图；通过 M0 交给对应模块。
- 可使用 M0 固定样例独立开发，不直接更改牛位置、苹果或分数，不自行处理音频或灵矽协议。

## 2. 执行步骤与阶段产物

| 阶段 | 工作 | 交付物 | 验证项 |
| --- | --- | --- | --- |
| M3-1：页面草图 | 准备、进行和结算布局，明确场景与输入区域 | 三种状态的移动端样例 | 规则、时间、得分和操作清楚可见 |
| M3-2：状态展示 | 接入快照、苹果寿命输入、计时计分和连接提示 | 固定数据驱动页面 | 展示与输入数据一致，无另一套计时规则 |
| M3-3：交互 | 接入方向、停止、开始、文字和录音手势 | 可记录意图的独立演示 | 一次操作只发一次意图，取消手势正确 |
| M3-4：异常与布局 | 权限拒绝、断网、重连、错误、软键盘和安全区域 | 异常状态与多尺寸样例 | 文字可继续使用，关键控制可触达 |
| M3-5：整合 | 对接真实游戏与音频状态，结束时禁用旧局操作 | 完整页面与验证记录 | 操作结果与实际执行一致 |

## 3. 必验标准

| 编号 | 给定条件与操作 | 预期结果 | 验证方式 |
| --- | --- | --- | --- |
| M3-A01 | 加载准备、进行、结算三组快照 | 每种状态显示对应内容；结算分数不因重新渲染变化 | 固定样例截图 |
| M3-A02 | 首次打开并查看配置，再输入空字符串、文本、0、负数及有效正数 | 默认显示 10 秒；非法输入明确提示且不能带入本局，合法输入仅影响新局 | 表单交互记录 |
| M3-A03 | 连接未就绪时点击开始，随后收到就绪并快速重复点击 | 未就绪不发起运行中的局；一次开始意图未完成时不重复请求开局 | 意图计数与状态记录 |
| M3-A04 | 从快照更新分数、剩余时间、疲惫与连接状态 | 展示值与快照一致；不会由页面每秒减数或点击按钮直接加分 | 数据对照与实现审查 |
| M3-A05 | 点击四个方向、转圈及停止，并分别返回接受、完成、取消、拒绝 | 动作意图正确；等待不被展示为完成，失败有对应提示 | 意图与结果记录 |
| M3-A06 | 提交普通文字、动作文字、空白文字，并在提交后收到回复 | 非空输入提交一次；空白不发请求；玩家输入、识别文字和实际回复可区分 | 交互记录 |
| M3-A07 | 按住说话后正常松手、滑出取消、触发系统手势或切到后台 | 正确结束或取消录音意图，不出现永久录音状态 | 手势记录，与 M4 联验 |
| M3-A08 | 拒绝麦克风权限，再尝试文字和方向按钮 | 显示可理解提示，文字和按钮仍可用；不循环强制弹权限框 | 浏览器和真机操作记录 |
| M3-A09 | 连接中断、重连或收到英文协议错误 | 显示相应中文状态，不误称已经完成动作，不泄露凭证或内部调用细节 | 异常样例截图 |
| M3-A10 | 在 320、375、390、430、768 像素宽度及软键盘打开时操作 | 无横向溢出、重叠遮挡；输入、发送和停止可触达；场景容器尺寸正确传给 M2 | 各尺寸截图与真机操作 |
| M3-A11 | 截止事件到达后再点动作，随后再来一局 | 旧局不再提交运动；新局清理旧字幕状态和计分展示，配置仍由新局确认 | 状态与请求记录 |
| M3-A12 | 使用键盘切换控件及屏幕阅读标签检查核心按钮 | 控件有明确名称，焦点可见，开始、发送和停止无需悬浮才能操作 | 手动检查记录 |

剩余时间的显示取整方式由共享契约登记，但不能在逻辑仍运行时显示已结算，也不能因显示四舍五入让本局提前或延后结束。

## 4. 联调、交付与阻塞

交付页面、样式、固定样例演示、事件接线说明和全部验收证据。与 M1 联验真实状态，与 M2 联验空间布局，与 M4 联验录音和打断，与 M5 联验实际聊天与连接错误。

模拟回复只用于布局和交互验证，不能宣称真实聊天通过。根应用装配或共享类型变化交 M0 统一维护。
