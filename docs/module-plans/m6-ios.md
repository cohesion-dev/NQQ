# M6 执行计划：iOS 外壳

本计划面向 iOS 负责人，目标是让同一套游戏页面在系统网页容器中正确采音、播放和处理生命周期。状态为待评审、未实施；原生边界依据[实现方案](../implementation-plan.md)，验收记录见[统一要求](README.md)。

## 1. 范围、依赖与交付

- 负责 `ios/`、原生运行配置、调试和真机说明。
- 使用 WKWebView（iOS 系统网页容器）加载共享游戏页面，不重写计时、苹果、动作或计分规则。
- 输入：M0/M3 的网页入口，M4 的网页音频行为，M5 的同源加密站点与会话。
- 输出：麦克风权限与媒体采集授权、原生音频会话、前后台通知及真机验证记录。

外壳与权限演示可用简单测试页先开发；最终验收需要实际游戏站点、目标 iPhone、可用签名配置及真实灵矽账号。网页版本可以先交付，但未经真机检查不能把 iOS 模块标为通过。

## 2. 执行步骤与阶段产物

| 阶段 | 工作 | 交付物 | 验证项 |
| --- | --- | --- | --- |
| M6-1：运行基础 | 建立薄外壳，加载测试页，登记系统与签名条件 | 可在目标机启动的开发工程 | 网页可见，地址和加载错误可诊断 |
| M6-2：权限与音频 | 配置麦克风用途、网页媒体授权和音频会话，与 M4 验证录音回放 | 真机权限与音频演示 | 允许、拒绝、停止及再次使用行为准确 |
| M6-3：生命周期 | 将前后台、锁屏和系统音频中断转为共享网页事件 | 原生到网页的生命周期适配 | 不重复启动，不恢复旧流，不暂停本局截止 |
| M6-4：完整游戏 | 加载实际站点，验证页面、灵矽语音和一分钟结算 | 完整真机体验与录屏 | 同一套页面完成真实抓取和聊天 |
| M6-5：交接 | 登记实际最低已验证系统、构建、签名与运行方式 | 可重复运行说明、问题清单和验收证据 | 新环境可按说明运行开发版本 |

最低支持版本和设备范围按实际测试结果登记。签名材料通过本地配置提供，不写入仓库；本计划不包含未经授权的商店提交或公开发布。

## 3. 必验标准

| 编号 | 给定条件与操作 | 预期结果 | 验证方式 |
| --- | --- | --- | --- |
| M6-A01 | 在目标 iPhone 安装并启动开发版本 | 加载共享游戏页面，界面与浏览器版本对应，无另一套原生游戏规则 | 真机记录和页面版本标识 |
| M6-A02 | 断开站点访问或制造页面加载失败，再恢复网络 | 可理解地提示失败并允许重试，不显示空白后无任何反馈 | 故障与恢复录屏 |
| M6-A03 | 首次请求录音，分别允许和拒绝 | 系统用途说明明确；允许后可采集，拒绝后仍可文字游戏，不反复强制弹窗 | 两种权限路径记录 |
| M6-A04 | 在系统设置恢复权限，再回到游戏主动录音 | 按实际权限状态重新启用，不需要重装；无重复麦克风会话 | 设置切换与轨道状态记录 |
| M6-A05 | 请求来自非游戏来源的媒体采集 | 不自动授予，游戏来源权限不被复用给其他页面 | 来源检查与开发测试 |
| M6-A06 | 完成真实语音问答、动作、播报和再次开麦 | 可录可播，打断后旧回复不重放；与 M4/M5 参数和代次一致 | 真实链路及听感记录 |
| M6-A07 | 在本局第 15 秒进入后台，约 10 秒后恢复 | 麦克风、播放和动作停止；恢复只剩原截止时间之前的时间，没有重新获得一分钟 | 服务端截止记录与真机演练 |
| M6-A08 | 在本局中锁屏，原截止时间后再解锁 | 直接显示原局结算，不补抓苹果、不重放旧动作或旧音频 | 锁屏前后状态及截止记录 |
| M6-A09 | 收到系统音频中断并恢复应用 | 中断期间释放或暂停相应媒体能力；恢复不擅自开麦，玩家可再次主动使用 | 中断场景与轨道记录 |
| M6-A10 | 打开软键盘，输入文字，操作发送和停止，并检查安全区域 | 关键输入和控制可达，不被键盘或系统区域遮挡；与 M3 布局一致 | 目标设备截图与操作 |
| M6-A11 | 连续三局开始、录音、结算、再来一局 | 没有重复网页实例、媒体任务或生命周期监听；无上局状态泄漏 | 多局录屏及资源对照 |
| M6-A12 | 默认规则下完整玩一次一分钟游戏，再按照说明重新运行开发版本 | 完成语音抓取和正确结算；实际运行步骤、系统与设备有记录 | 完整录屏、分数事件与运行复核 |

后台时间以实际记录为准，上表“约 10 秒”只是操作步骤；预期剩余时间由原截止时刻计算，不能直接在恢复时写死为 35 秒。原生系统调度造成的画面更新延后不改变规则截止时间。

## 4. 联调、交付与阻塞

交付原生外壳、配置与运行说明、媒体授权和生命周期约定、目标系统清单、真机验收记录及未完成项。与 M3 联验布局，与 M4 联验采音和播放，与 M5/M0 联验截止和恢复。

模拟器或桌面浏览器结果只能标为对应环境验证。没有真机、签名或实际游戏站点时记录相关项阻塞，不以简单测试页的通过替代完整游戏验收。
