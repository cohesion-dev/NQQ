# 牛七七

三分钟语音陪伴与蒙眼抓苹果小游戏。打开应用后默认聊天，玩家说“我想玩抓苹果”才进入游戏，靠近苹果自动装入口袋。

## 当前实现

- 面向 iPhone 12 Pro Max 竖屏的移动网页：使用动态视口高度和安全区域，默认显示聊天模式，游戏模式显示规则、挑战和结算。
- 每局固定 3 分钟，同时最多两颗苹果；苹果存活 1 分钟，页面不提供修改入口。
- 抓到加 1 分；抓到或过期后，独立等待 1 秒补位。过期不扣分。
- 连续移动、转圈、停止、边界和路径抓取；三个小步或转圈后疲惫，仍可继续移动。
- 优先加载 `assets/niu_qi_qi.glb`，包含 34 个骨骼和 19 个动画片段；加载失败时使用程序化牛兜底，详情见[模型动作清单](docs/model-assets.md)。
- 行走和转身使用模型自带动画。当前模型没有表情变形数据，命名的头部和眼部骨骼只能提供简单表现；程序化牛的丰富表情不代表导入模型已具备相同能力。
- 角色回复播放灵矽下发的真实语音，音色使用当前智能体在控制台的配置；Opus（音频压缩编码格式）由 WebAssembly（浏览器可运行的二进制模块）解码。抓取和疲惫仍使用本地短音效。
- 应用启动后自动保持语音通话连接；聊天模式只显示居中的牛七七和最近对话文字，不显示按钮。
- 聊天模式使用正视镜头；可通过灵矽调用 `spin` 围绕中心走一圈、`somersault` 翻跟头或 `dance` 跳舞，动画完成后才回传结果。两种模式绕圈均约 4.2 秒，腿部迈步并沿行进方向转身，结束回到起点面向前方；游戏中正常抓取沿途苹果，触边提前结束，停止保留当前位置。进入游戏后切换到斜上方抓苹果视角并显示眼罩。
- 聊天双方结束说话后静默 5 秒，开始连续随机表演四种舞蹈/舞台步行；每支结束停 0.5 秒再随机续播，用户开口或指令到达立即停止自动表演，对话结束后重新等 5 秒。主动跳舞同样随机，翻跟头使用 `Backflip`；游戏移动正常跑步、疲惫走路，左右转身和回正使用对应站立转身片段。
- VAD（Voice Activity Detection，语音活动检测）会按“有声音到无声音”自动切分对话轮次；最多保留最近 100 条对话文字。
- 说“我想玩抓苹果”后进入游戏模式，显示数字倒计时和得分，不显示倒计时文字描述。
- 聊天和游戏都不提供方向按钮、电话按钮、停止按钮或文字输入。
- 已实现激活绑定、工具发现、请求去重、工具结果回传、文字提交和麦克风音频上传的接入代码；已用真实牛七七智能体验证握手和工具发现，**文字/语音驱动游戏仍待页面联调**。

目前未制作原生 iOS 外壳，未完成 iPhone 真机验收；页面设计用于后续由 WKWebView（iOS 系统网页容器）复用。

## 本地运行

### 1. 准备环境与配置

使用 Node.js（服务端 JavaScript 运行环境）22.12 或更新版本，建议使用 22.x；浏览器需支持麦克风、音频工作线程和三维渲染。以下命令均在包含 `package.json` 的仓库根目录执行：

```sh
node --version
npm --version
npm ci
cp -n .env.example .env
```

`cp -n` 不覆盖已有 `.env`。编辑本地 `.env`，按下表填写配置；不要把真实密钥写入文档或前端代码。

| 配置项 | 是否必填 | 作用 |
| --- | --- | --- |
| `LINX_AGENT_ID` | 真实语音接入必填 | 灵矽牛七七智能体编号 |
| `LINX_API_KEY` | 可选 | 自动将激活设备绑定到该智能体的访问密钥 |
| `LINX_DEVICE_ID` | 可选 | 复用已有绑定设备；不填则按浏览器会话分配虚拟设备 |
| `PORT` | 可选 | 构建后独立服务的端口，默认 `8787`，不影响开发端口 |

在灵矽控制台准备支持工具调用的智能体，角色提示可参考[牛七七提示词](docs/linx-agent-prompt.md)。完整绑定步骤见[灵矽联调指南](docs/linx-integration.md)。未配置灵矽时仍可查看模型和页面，但不能通过真实语音聊天、执行指令或开始游戏。

### 2. 启动开发服务

```sh
npm run dev
```

打开终端显示的地址，通常为 `http://127.0.0.1:5173/`。Vite（前端开发与构建工具）同时挂载页面和灵矽网关，**不需要再开一个终端启动 `npm run server`**。按 `Ctrl+C` 停止服务；修改 `.env` 或网关代码后重启服务并刷新页面。

端口被占用时，以终端实际打印的地址为准；也可以指定开发端口：

```sh
npm run dev -- --port 5174
```

另开终端可检查配置是否被服务读取：

```sh
curl -fsS http://127.0.0.1:5173/api/config
```

已填写智能体编号时返回 `{"configured":true,"sound":"linx-stream"}`。`configured` 只表示配置了编号，不代表设备绑定、握手或真实语音已经成功；使用其他端口时同步修改检查地址。

### 3. 首次体验

1. 页面默认正视牛七七，自动建立灵矽连接；握手和工具发现完成后申请麦克风，允许浏览器使用麦克风。若提示播放受限，轻触页面解锁声音。
2. 如果显示激活码，在控制台绑定到该智能体后刷新页面；已有配置的固定设备同时只能由一个页面使用。
3. 说“你是谁”测试问答，再说“跳舞”“翻跟头”或“转圈圈”测试聊天动作；双方结束说话后静默五秒会连续随机跳舞，开口即可打断。
4. 说“我想玩抓苹果”，成功调用开始游戏工具后切换视角并显示倒计时与得分；可说“向左走两步”“转圈圈”“停下”“退出游戏”。
5. 到三分钟时结算并回到聊天视图。结算后保留语音监听，本地结算提示仅显示字幕；角色问答声音均来自灵矽。页面没有电话、方向、停止或重试按钮，也没有文字输入框；连接或权限失败后按提示处理并刷新页面。

本地电脑可使用回环地址。手机访问不能使用电脑的 `127.0.0.1`；当前服务也只监听本机。真机联调需另行提供手机可访问的 HTTPS（加密网页传输协议）入口，并转发网页、`/api/` 请求和 `/api/linx` 双向连接，不能只修改页面地址。原生外壳和真机验收尚未完成。

## 构建后运行

完成上述依赖安装和 `.env` 配置后，在项目根目录运行：

```sh
npm run build
npm run server
```

默认打开 `http://127.0.0.1:8787/`，如配置 `PORT` 则使用对应端口。独立服务从 `dist/` 读取页面和模型，同时提供与开发模式相同的网关接口。修改前端代码或素材后重新构建，再刷新页面；修改服务端配置或代码后重启服务。

当前服务直接运行 TypeScript（带类型检查的 JavaScript），启动依赖 `tsx`，因此安装时需要保留开发依赖。`dist/` 仅包含前端产物，单独上传到静态托管不能提供灵矽设备连接；运行服务还需要 `server/`、`shared/`、依赖和本地配置。

设备身份映射保存在根目录 `.linx-devices.json`，与 `.env` 一样已被 Git 忽略。刷新页面不会恢复上一局分数；重启服务会断开连接，当前没有跨连接续局功能。以上为本地运行方式，公开部署还需补齐访问控制和 HTTPS 入口。

## 常见运行问题

| 现象 | 处理方式 |
| --- | --- |
| `LINX_NOT_CONFIGURED` | 检查根目录 `.env` 的 `LINX_AGENT_ID`，重启服务并刷新页面 |
| 页面显示激活码 | 在灵矽控制台完成绑定，再刷新；未提供 `LINX_API_KEY` 时需要手动绑定 |
| `DEVICE_IN_USE` | 关闭占用相同 `LINX_DEVICE_ID` 的另一页面后刷新 |
| `LINX_SETUP_TIMEOUT` 或连接失败 | 检查网络、设备绑定、智能体工具能力；更多错误见[联调指南](docs/linx-integration.md#5-常见提示) |
| 麦克风不可用 | 检查浏览器站点权限和访问地址；重新授权后刷新，真机使用可访问的加密入口 |
| 有字幕但没有声音 | 轻触页面允许播放；确认控制台音色已保存、当前智能体编号一致，并在修改后刷新页面建立新连接；移动端仍需真机验证 |
| 页面或模型返回 `Not found` | 独立服务先执行构建，并确认从仓库根目录启动；模型源文件是 `assets/niu_qi_qi.glb` |

## 检查

```sh
npm test
npm run typecheck
npm run build
```

规则测试使用可控时间，覆盖三分钟截止、苹果生命周期、连续移动和真实接触时刻、停止与疲惫；音频测试验证 44.1kHz/48kHz 输入转换为 16kHz 单声道的分帧采样数，以及实际 Opus 解码、连续播放调度、正常结束排空、取消和重连隔离。

开发服务器运行时，可另开终端执行浏览器检查：

```sh
npx playwright install chromium
npm run test:browser
```

也可通过 `NQQ_BROWSER_PATH` 指定本地 Chromium（浏览器引擎）可执行文件。浏览器检查使用模拟网关消息，在 428×926 和 428×746 可见区域检查仅语音界面、工具执行、疲惫、权限拒绝和三分钟结算，结果截图位于 `test-results/`；它不替代真实灵矽语音和 iPhone 真机验收。
