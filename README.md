# 牛七七

牛七七是一款面向浏览器和 iOS `WKWebView` 的语音互动小游戏。玩家可以通过语音或文字指挥一只蒙眼的卡通牛，在一分钟内移动并抓取场景中的苹果，同时向角色提问普通问题。

## 当前状态

项目目前处于初始化和方案评审阶段。仓库现有完整的实现方案，但还没有前端、接入网关、iOS 外壳、测试代码或 CI 配置。

详细设计见 [`docs/implementation-plan.md`](docs/implementation-plan.md)。

## 首版玩法

- 每局固定 60 秒。
- 开局随机出现 2 个苹果，场内最多同时有 2 个可抓取苹果。
- 每个苹果默认存活 3 秒，可在开局前调整；本局开始后保持不变。
- 抓到苹果得 1 分，抓取成立后 1 秒补充一个新苹果。
- 苹果过期不扣分，过期后 1 秒补充一个新苹果。
- 到达 60 秒后停止移动、抓取和补位，并展示最终抓取数量。

## 技术方案

前端计划使用 Vite、原生 TypeScript 和 Three.js，负责页面、三维场景、游戏时钟、苹果生命周期、碰撞、计分和动作执行。Node.js + TypeScript 接入网关负责浏览器会话、灵矽设备连接、鉴权、音频适配和工具路由。iOS 端通过 `WKWebView` 复用同一套页面。

游戏规则由本地页面确定，灵矽负责语音识别、意图理解、工具调用、普通问答和语音合成。灵矽不能直接决定游戏时钟、苹果位置或最终分数。
