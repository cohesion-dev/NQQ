# 牛七七

三分钟语音陪伴与蒙眼抓苹果小游戏。打开应用后默认聊天，玩家说“我想玩抓苹果”才进入游戏，靠近苹果自动装入口袋。

## 当前实现

- 面向 iPhone 12 Pro Max 竖屏的移动网页：使用动态视口高度和安全区域，默认显示聊天模式，游戏模式显示规则、挑战和结算。
- 每局固定 3 分钟，同时最多两颗苹果；苹果存活 1 分钟，页面不提供修改入口。
- 抓到加 1 分；抓到或过期后，独立等待 1 秒补位。过期不扣分。
- 连续移动、转圈、停止、边界和路径抓取；三个小步或转圈后疲惫，仍可继续移动。
- 优先加载 `assets/niu_qi_qi.glb`，包含 34 个骨骼和 19 个动画片段；加载失败时使用程序化牛兜底，详情见[模型动作清单](docs/model-assets.md)。
- 行走和转身使用模型自带动画。当前模型没有表情变形数据，命名的头部和眼部骨骼只能提供简单表现；程序化牛的丰富表情不代表导入模型已具备相同能力。
- 浏览器语音合成和简单音效作为声音占位，音色取决于系统，不是灵矽音频。
- 应用启动后自动保持语音通话连接；聊天模式只显示居中的牛七七和最近对话文字，不显示按钮。
- 聊天模式使用正视镜头；可通过灵矽调用 `spin` 围绕中心走一圈、`somersault` 翻跟头或 `dance` 跳舞，动画完成后才回传结果。聊天绕圈约 4.2 秒，腿部迈步并沿行进方向转身，结束回到起点面向前方。进入游戏后切换到斜上方抓苹果视角并显示眼罩。
- 聊天双方结束说话后空闲 10 秒，随机表演四种舞蹈/舞台步行之一；用户开口或指令到达立即停止自动表演，结束后重新等 10 秒。主动跳舞同样随机，翻跟头使用 `Backflip`；游戏移动正常跑步、疲惫走路，左右转身和回正使用对应站立转身片段。
- VAD 会按“有声音到无声音”自动切分对话轮次；最多保留最近 100 条对话文字。
- 说“我想玩抓苹果”后进入游戏模式，显示数字倒计时和得分，不显示倒计时文字描述。
- 聊天和游戏都不提供方向按钮、电话按钮、停止按钮或文字输入。
- 已实现激活绑定、工具发现、请求去重、工具结果回传、文字提交和麦克风音频上传的接入代码；已用真实牛七七智能体验证握手和工具发现，**文字/语音驱动游戏仍待页面联调**。

目前未制作原生 iOS 外壳，未完成 iPhone 真机验收；页面设计用于后续由 WKWebView（iOS 系统网页容器）复用。

## 本地运行

使用 Node.js（服务端 JavaScript 运行环境）22.12 或更新版本，在项目根目录运行：

```sh
npm ci
npm run dev
```

打开终端显示的地址，通常为 `http://127.0.0.1:5173/`。填写本地灵矽配置后即可聊天；说“我想玩抓苹果”才创建本局。开发模式将网页与网关挂在同一端口，不需要额外启动服务。

语音示例：`你是谁`、`给我讲个故事`、`我想玩抓苹果`、`向左走两步`、`停下`、`退出游戏`。页面不提供文字输入，所有内容均由灵矽理解。

## 对接真实灵矽

复制 `.env.example` 为 `.env`，填写 `LINX_AGENT_ID`。`LINX_API_KEY` 用于自动绑定新设备，可不填；未配置密钥时页面会显示激活码，在灵矽控制台绑定后重试即可。已有绑定设备可以填写 `LINX_DEVICE_ID`，同一个设备仅允许一个页面占用。

修改后重启 `npm run dev`，等待握手和工具发现完成后即可聊天。语音输入通过浏览器麦克风进入灵矽，回复文字由浏览器朗读；上游压缩语音暂不解码。

配置文件和设备会话记录已加入忽略列表，密钥只在服务端读取。详细控制台配置、工具名称、排查和实际限制见[灵矽联调指南](docs/linx-integration.md)。

## 检查

```sh
npm test
npm run typecheck
npm run build
```

规则测试使用可控时间，覆盖三分钟截止、苹果生命周期、连续移动和真实接触时刻、停止与疲惫；音频测试验证 44.1kHz/48kHz 输入转换为 16kHz 单声道的分帧采样数。

开发服务器运行时，可另开终端执行浏览器检查：

```sh
npx playwright install chromium
npm run test:browser
```

也可通过 `NQQ_BROWSER_PATH` 指定本地 Chromium（浏览器引擎）可执行文件。浏览器检查使用模拟网关消息，在 428×926 和 428×746 可见区域检查仅语音界面、工具执行、疲惫、权限拒绝和三分钟结算，结果截图位于 `test-results/`；它不替代真实灵矽语音和 iPhone 真机验收。

构建后可运行 `npm run server`，在 `http://127.0.0.1:8787/` 使用同源网页和网关。这是本地联调服务；真机麦克风需使用可访问的 HTTPS（加密网页传输协议）入口，公开部署的访问控制、域名和签名按后续发布方案处理。
